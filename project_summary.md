# Project Summary

## Title
Lateral Control for Lane Changing Manoeuvre

## Description
This MATLAB/Simulink project implements lateral and longitudinal control for an overtaking lane-change manoeuvre using decoupled vehicle dynamics.

## Key Work
- Built a Simulink model for lane-changing manoeuvre simulation.
- Implemented longitudinal speed control and lateral position control.
- Used PID controllers for vehicle speed and lane-change tracking.
- Performed robustness testing using Latin Hypercube Sampling.
- Analysed the impact of uncertainty in vehicle parameters such as mass, front cornering stiffness, and front axle distance.

## Skills Demonstrated
- MATLAB scripting
- Simulink modelling
- Vehicle dynamics
- Control systems
- PID tuning
- Robustness analysis
- Simulation-based validation
